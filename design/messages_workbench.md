# 手机消息工作台（导演布局的专属功能界面）

「每个功能都有专属界面」重建的第 1 批第三个功能。落在
`frontend/lib/features/messages/messages_workbench.dart`，由导演工作台的
「手机消息」功能（`_DirectorFeature.messages`）承载；主页「手机消息」卡片直接进入，
不再走通用配置表视图。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（190–224） | 搜索框 / ＋创建短信 / 短信列表（联系人、首条内容摘要、消息数） |
| 中（自适应） | 手机对话视图（状态栏、联系人标题、气泡、白雨选项）+ 编排按钮 + 保存条 |
| 右（≥1000 显示，288–330） | 短信设置或消息/回复设置 |

窄窗（<1000）自动隐藏右栏；<1250 收窄左右栏。

## 对话树模型（PhoneMsgCfg）

- 一条短信是一棵树：`next` 指向后续消息；没有被任何 `next` 引用的消息是**根**（一段对话）。
- `role == 0` 的消息是**白雨的回复选项**；其余 role 是联系人。
- id 约定同组消息共用 `floor(id / 100)`；新建子消息在组内找空位（组满顺延下一组）。
- 手机视图按「选择（缺省取第一条 next）」串成对话链；遇到白雨选项时停在该节点并把
  选项作为可点击的气泡展示；点选后继续展开后续。

## 编排操作

- **＋ 添加{联系人}信息**：在当前链尾追加联系人消息（若根为空则写入根内容）。
- **＋ 添加白雨信息**：追加一个白雨回复，并自动选中。
- **＋ 添加第二种回复**：为选中的联系人消息再加一个白雨回复（最多两个）。
- 点击气泡选中；右侧可编辑该条的短信内容、回复选项文字、条件/效果条数，并删除
  （删除此消息会连同其后续分支一起删除）。

## 右栏设置

- **短信设置**（选中根）：发送人（更换会同步整段对话的 role）、短信内容、触发条件 /
  阅读效果条数、删除这段短信。
- **白雨回复 / 联系消息**：短信内容、回复选项文字（白雨）、出现条件 / 阅读效果条数、
  删除此消息及后续分支。

## 数据与保存

- 单表整表读写：`PhoneMsgCfg`。
- 读取 `GET /api/cfg/PhoneMsgCfg`（`data` + `mtime_ns`）；写回 `PUT`，带
  `expect_mtime_ns`；409 弹「重新加载 / 强制覆盖」。
- 「保存修改」写回脏数据；「放弃修改」回滚到本次加载快照。

## 当前版本的边界

- **短信触发条件 / 阅读效果**（金钱、好感、状态变化等命令）未内嵌条件与效果编辑器，
  右栏只显示条数概况；这些复杂命令在通用配置表里维护。
- **原版手机界面贴图**（状态栏、气泡、壁纸等 sprite）与游戏内实时预览未接入，
  用简化的手机外观与静态对话链替代。
- **编辑用短信名称**（对标存于 editor.titles）与预览等待时间未持久化。
