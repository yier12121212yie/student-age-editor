# JSON 侧栏工作台（导演布局的专属功能界面）

「每个功能都有专属界面」重建的第 3 批第二个功能。落在
`frontend/lib/features/json/json_workbench.dart`，由导演工作台的「JSON 侧栏」功能
（`_DirectorFeature.json`）承载；主页「JSON 侧栏」卡片直接进入。

对标把「JSON 侧栏」做成编辑器内的**当前记录原始 JSON** 查看 / 写入面板；这里重建为
**三栏工作台**：从配置表清单里选表，逐条记录查看与编辑其 JSON，校验通过后整表写回。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（260–300） | 配置表搜索 + 表清单（来自 `editorPages` 的全部 cfgNames + 补充表） |
| 中（自适应） | 顶部表信息条（表名、记录数、重新加载 / ＋记录 / 删除记录）＋ 记录列表（210）＋ JSON 编辑器 ＋ 保存条 |
| 右（≥1080 显示，260–300） | 表信息（记录数 / 序列化大小 / mtime）＋ 当前记录（编号 / 解析状态）＋ 说明 |

窄窗（<1080）自动隐藏右栏；<1340 收窄左右栏。

## 配置表清单

- 汇总 `editorPages` 中所有 `cfgNames`，并补充常规工作台之外值得直编的表
  （`MinigameCfg`、`MinigameActionCfg`、`KZone*`、`InteractCfg` 等）。
- 支持按表名搜索（如 `EvtCfg`）。

## 记录与 JSON 编辑

- 选中表后按 `GET /api/cfg/<name>` 读取整表，记录列表按编号排序，并显示
  `name` / `title` / `text` / `content` / `desc` 中第一个非空字段作为标签。
- 编辑器把选中记录格式化为 2 空格缩进 JSON；每次输入即时解析：
  - 合法对象 → 写回内存（置脏），标记「JSON 有效」；
  - 非法 → 保留文本、标记「JSON 有误」并禁止保存。
- 「格式化」按当前记录重新缩进；「＋ 记录」以自定义编号新建空对象；「删除记录」带确认。

## 数据与保存

- 选中表整表读写：`GET /api/cfg/<name>`（`data` + `mtime_ns`）；`PUT` 带
  `expect_mtime_ns`，409 弹「重新加载 / 强制覆盖」。
- 「保存修改」在校验通过时写回整表；「放弃修改」回滚到本次加载快照。
- 保存按钮在存在解析错误时禁用，避免写坏磁盘。

## 当前版本的边界

- **只做记录级 JSON**：以「记录」为单位编辑，不以整表大文本形式编辑（表可能很大）。
- **不做字段类型约束**：只校验「是 JSON 对象」，不校验字段类型 / 枚举 / 引用是否合法；
  常规编辑请优先使用专属工作台，避免破坏字段类型（界面内已提示）。
- **不做撤销 / 重做栈**：仅「放弃修改」回滚到本次加载快照。
- **不做 schema 提示**：未内联字段名 / 类型提示。
- **表清单为编辑器功能面 + 补充表**：未列出全部 406 张表，避免噪音。
