# 导演工作台（导演 UI 模式）

第 4 个顶层界面模式（`UiMode.director`），从设置页「界面风格」或状态栏/顶栏的模式切换进入。
整壳落在 `frontend/lib/features/shell/director_shell.dart`，风格是**功能总览为首页的剧情工作台**。

## 进入即首页

进入导演布局先展示「主页」，而不是直接落到某个编辑器。主页结构：

- 标题「模组编辑功能」+ 说明「选择要编辑的内容。各功能默认只显示这个模组的记录。」
- 右上角显示当前模组。
- **搜索框**：按标题/描述过滤功能卡片。
- **收藏区**：点卡片右上角星标收藏；收藏项持久化在本地
  `SharedPreferences`（键 `director_home_favorites_v1`）。
- **游戏内置编辑器可编辑项**：剧情舞台 + `pages_catalog` 的全部编辑页面，每页一张卡片；
  点页面卡片直接进入配置表工作台并定位到该页。
- **编辑器拓展**：插件 / 文件 / 云同步 / 全局搜索 / 扫描修复。
- **模组管理**：模组信息 / 游戏素材缓存 / 导出导入 / 删除模组。
- **素材库**：资源页入口。

卡片信息：图标 + 标题 + 描述 + 「打开 →」+ 右侧提示；右上角星标收藏。

## 顶部工程栏

品牌 + 视图历史（前进 / 后退）+ 当前模组下拉 + 「功能」下拉 + 刷新 + 常用入口
（主页 / 模组 / 云同步 / 操作说明 / 设置 / AI / 界面布局切换）。
功能视图**懒加载保活**：切走再切回不丢状态；刷新仅重挂当前视图。

## 各功能视图

- **剧情舞台**：`StoryStudioEditor` 三栏（对话线 / 舞台编辑 / 人物表情）。切走守卫：
  有未保存修改时切模式 / 切模组 / 刷新会拦下确认。
- **人物工作台**（专属界面，第 1 批重建的第一个功能）：`PersonWorkbench` 三栏
  （人物列表 / 标签表单 / 立绘预览），不再套用通用配置表视图。详见
  `design/person_workbench.md`。
- **社交动态**（专属界面，第 1 批第二个功能）：`SocialWorkbench` 三栏
  （动态列表 / 正文与评论树 / 动态·评论设置）。详见 `design/social_workbench.md`。
- **手机消息**（专属界面，第 1 批第三个功能）：`MessagesWorkbench` 三栏
  （短信列表 / 手机对话视图 / 短信设置）。详见 `design/messages_workbench.md`。
- **目标工作台**（专属界面，第 1 批第四个功能）：`GoalsWorkbench` 三栏
  （目标列表 / 游戏内预览 / 目标设置标签）。详见 `design/goals_workbench.md`。
- **积木库**（专属界面，第 2 批开工）：`BlocksWorkbench` 三栏
  （积木目录 / 构建清单 + 输出 / 说明），把条件·效果·指令的代码行做成可视化积木。
  同时**替换了原先无代码模式的条件/效果编辑入口**：字段内新增「打开积木库」，
  目录浏览也升级为分类（游戏 `ConditionTypeCfg` / `EffectTypeCfg`）+ 分页。
  详见 `design/blocks_library.md`。
- **事件工作台**（专属界面，第 2 批第二个功能）：`EventWorkbench` 三栏
  （事件列表 / 事件详情 / 概览与引用）。触发条件与事件效果直接复用「积木库」。
  详见 `design/event_workbench.md`。
- **闲聊**（专属界面，第 2 批第三个功能）：`IdleChatWorkbench` 三栏
  （闲聊列表 / 闲聊设置 + 线性对白链 / 对话预览）。条件与效果复用「积木库」。
  详见 `design/idle_chat_workbench.md`。
- **配置表工作台**：顶部页面标签 + `SchemaEditorView`（条目列表 / 字段表单）+ 右侧信息栏
  （页面说明与本页可编辑表，可切换当前表）。与经典/创作的「页面视图」不同。
- **其余功能**（素材库 / 文件 / 插件 / 云同步 / 模组 / 搜索 / 修复）：包一层导演外框
  （`← 全部功能` 面包屑 + 功能标题 + 说明），正文复用现有页面。

## 右下角快捷工具托盘

常驻圆形按钮：操作说明 / 模组管理 / 设置 / AI，末尾箭头可收起展开；收起态 AI 悬浮按钮
与托盘错位不重叠。

## 操作说明

覆盖层列出工程栏、功能模块、配置表工作台、快捷工具与常用快捷键，并带功能跳转 chip。

## 配色

一律取自 `core/app_theme.dart` 的 `palette` / `accentColor`，随亮/暗外观联动；
未新增硬编码色值（由 `test/light_theme_audit_test.dart` 守门）。
