# 事件工作台（导演布局的专属功能界面）

「每个功能都有专属界面」重建的第 2 批第二个功能。落在
`frontend/lib/features/events/event_workbench.dart`，由导演工作台的
「事件工作台」功能（`_DirectorFeature.events`）承载；主页「事件」卡片直接进入，
不再走通用配置表视图。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（260–300） | 搜索框 / ＋新建事件 / 排序切换（ID·名称）/ 删除事件 / 筛选胶囊 / 事件列表 |
| 中（自适应） | 事件详情：基本信息 / 触发与效果 / 对白入口 / 选项 / 其他数组 / 内容与说明 + 保存条 |
| 右（≥1040 显示，300–340） | 概览 / 首句预览 / 触发条件 / 被引用 |

窄窗（<1040）自动隐藏右栏；<1320 收窄左右栏。

## 事件列表

- 筛选组（事件类型 id 集合）：全部 / 回合开始 / 结束回合 / 行动 / 社交 / 关系 / 按钮 / 其他。
- 搜索：标题、`content`、`desc`、事件编号。
- 卡片：标题、编号、类型名、可达对白句数、触发条件摘要。
- 排序：按 ID 或按名称。

## 详情分区

- **基本信息**：标题、事件类型（`EvtTypeCfg` 下拉）、显示方式 `displayType`、
  触发概率 `rate`（0~1）、次数上限 `maxcount`、关联人物 `npc`（人物选择器）、
  权重 `weight`、地图 `mapId`、最大选项数 `maxoptions`。
- **触发与效果**：`condition` / `effect` 两条，点击**直接打开积木库**可视化编辑
  （条件用 `condition` 模式、效果用 `effect` 模式），完成即写回 2D 数组。
- **对白入口** `talkId`：对白列表（内容 + 发言人预览），可上移 / 下移 / 删除，
  「＋ 添加对白入口」从 `TalkCfg` 选择器加入；标题栏显示从入口出发的**可达对白句数**
  （沿 `nextTalk` / `nextTalk2` 与选项 `talkId` / `talkId2` 遍历）。
- **选项** `options`：`OptionCfg` 列表（内容预览），可增删移序。
- **其他数组**：`miniGame` / `probability` / `replace` 的数值 chips 编辑器。
- **内容与说明**：`content`（无对白事件正文 / 通知）与 `desc`（内部说明）。

## 右栏

- **概览**：类型名、对白入口数、可达对白句数、选项数、触发概率百分比。
- **首句预览**：入口第一句对白；无对白时提示走事件效果。
- **触发条件**：条数或「未设置」。
- **被引用**：扫描其它事件的 `replace` 与本模组选项的 `nextEvtId`，列出引用来源。

## 数据与保存

- 编辑并整表写回 `EvtCfg`：读取 `GET /api/cfg/EvtCfg`（`data` + `mtime_ns`），
  写回 `PUT` 带 `expect_mtime_ns`，409 弹「重新加载 / 强制覆盖」。
- `EvtTypeCfg` 用于类型名与下拉；`TalkCfg` / `OptionCfg` **只读**，懒加载用于预览。
- 条件 / 效果走共享「积木库」（`features/blocks/`），复用同一套行模型与序列化。
- 「保存修改」写回脏数据；「放弃修改」回滚到本次加载快照。

## 当前版本的边界

- **对白 / 选项内容本身不在此编辑**：`TalkCfg` / `OptionCfg` 只读预览，实际内容去
  剧情处理 / 剧情舞台编辑（未做从事件直达对应对白的深链跳转）。
- **原版事件浏览与「覆盖到当前模组 / 撤销覆盖」**未接入（对标有该能力）。
- **社交 / 礼物 / 行动触发的专用绑定编辑器**（对标 `event-bindings.js` 的
  social/gift/action 绑定）未接入，只保留 `EvtCfg` 原生字段。
- **自定义筛选标签**（对标可保存到本机的标签组）未接入，只有内置筛选组。
- **显示方式 `displayType`** 按数字维护（对标是从类型与社交绑定派生的复合值）。
