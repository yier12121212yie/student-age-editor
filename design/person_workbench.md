# 人物工作台（导演布局的专属功能界面）

按「每个功能都有专属界面」的批次规划重建的第一个功能。落在
`frontend/lib/features/person/person_workbench.dart`，由导演工作台的「人物工作台」
功能（`_DirectorFeature.person`）承载；主页「人物」卡片直接进入本工作台，
不再走通用配置表视图。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（214–244） | 搜索框 / ＋添加角色 / 创建副本 / 删除角色 / 人物列表（50 条一页，分页） |
| 中（自适应） | 四个标签 + 表单 + 底部保存条 |
| 右（≥980 显示，262–320） | 立绘预览：小学/中学切换、图片、表情与服装下拉 |

窄窗（<980）自动隐藏右栏，保证中栏可用；<1180 收窄左右栏。

## 标签页

1. **人物资料**：姓名 / 性别（男·女切换）/ 出生日期（年·月·日）/ 人物介绍 /
   小学·中学立绘（点击选择图片）/ 电话 / 普通·恋爱昵称 / 备注 / 可社交开关 /
   企鹅头像编号 / 点击音效编号。
2. **成长与喜好**：初始属性（智力·情商·体魄滑杆）/ 属性成长（12 学年可多选，
   调一次应用到所选学年）/ 性格 MBTI（四维二选一 + 编码输入 + 类型名）/ 礼物喜好
   （11 类物品加减器 + 数值）/ 重点属性·特质·特长（引用下拉）/ 携带物品·初始状态
   （多选弹窗）/ 所在班级·考试排名·学习排名 / 关联小游戏·排序。
3. **表情与服装**：服装槽（默认 + 附加）/ 加入·删除服装 / 当前服装的立绘网格
   （点选表情、悬停删除非默认项）/ 添加立绘图片 / 表情名称。
4. **图片与大小**：`urlParm` / `urlParm2`（X·Y·缩放）/ `bubbleParm` / `bubbleParm2`
   气泡高度 / `l2d` / `l2d2` 模型名。

## 数据与保存

- 三张表整表读写：`PersonCfg` / `PersonGrowCfg` / `ModFaceCfg`；
  引用表 `PersonAttrCfg` / `TraitsCfg` / `PersonStateCfg` / `ItemTagCfg`（懒加载），
  `ItemCfg` 在打开物品选择器时再拉。
- 立绘目录来自 `GET /api/roles`（`portrait1` = 小学 `url`，`portrait2` = 中学 `url2`）。
- 读取：`GET /api/cfg/<name>`（`data` + `mtime_ns`）。
- 写回：`PUT /api/cfg/<name>`，带 `expect_mtime_ns`；409 弹「重新加载 / 强制覆盖」。
- 「保存修改」一次写回三张表的脏数据；「放弃修改」恢复到本次加载的快照。
  底部保存条实时显示「有未保存的修改 / 已与磁盘同步」。

## 与对标的功能差异（当前版本有意保留的边界）

- **Live2D 实时预览与拖拽调参**：未接入实时模型渲染，改为数值编辑 + 静态立绘对照。
- **企鹅头像图片导入 / 恋爱扩展 / 小游戏库 / 物品仓库卡片选择器**：未接入，
  头像以编号、物品/状态以多选弹窗简化。
- **服装名称自定义 / 位置规则提示**：服装以槽位命名（服装 1..9）。
