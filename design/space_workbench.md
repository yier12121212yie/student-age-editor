# 空间工作台（导演布局的专属功能界面）

「每个功能都有专属界面」重建的第 2 批第四个功能。落在
`frontend/lib/features/space/space_workbench.dart`，由导演工作台的「空间」功能
（`_DirectorFeature.space`）承载；主页「空间」卡片直接进入。

企鹅空间 = 人物的主页（资料 + 个性签名 + 留言板）。对标把空间拆成
“空间外壳（person pigeon space）+ 留言板 + 主题/字体/签名渲染”，这里重建为
**三栏工作台**，并刻意不引入对标的本地 MP3 播放器与游戏字体图集签名渲染。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（260–300） | 搜索（人物/昵称）/ ＋为人物添加空间 / 删除此空间 / 空间列表（头像、人物名、昵称、编号） |
| 中（自适应） | **游戏内空间预览**：封面 + 头像 + 昵称 + 个性签名 + 导航标签（主页/说说/留言板/个人档）+ 内容 + 保存条 |
| 右（≥1040 显示，300–350） | 两个分段：**空间设置**（资料 / 个性化 / 个人档）与 **留言板**编辑 |

窄窗（<1040）自动隐藏右栏；<1320 收窄左右栏。预览用主题（`KZoneColorCfg`）的
`bg`/`imgColor`/`navBg`/`nameTxt` 数据驱动配色，尽量还原游戏内观感。

## 空间设置（KZoneProfileCfg）

- **资料**：企鹅昵称 `name`、个性签名 `desc`、开通黄钻 `isVip`（0/1）、更换头像 `icon`。
- **个性化**：空间主题 `theme`（下拉，取 `KZoneColorCfg`）、字体 `font` 与
  字体颜色 `fontColor`（下拉，取 `KZoneFontCfg`）、签名字号 `fontSize`（40–80）、
  背景音乐编号 `bgm`（`AudioCfg` 编号，0 = 无）。
- **个人档**：家乡 `hometown`、现居地 `living`、职业 `job`、学校/公司 `school`、
  感情状态 `marriage`（`[0]` 未恋爱 / `[1]` 恋爱中）。

## 空间预览

- **主页**：签名 + 标签（黄钻 / 主题 / 背景音乐）。
- **说说**：提示动态（`KZoneContentCfg`）在「社交动态」工作台编辑，此处不重复。
- **留言板**：按留言人渲染气泡（含「私密」标记）。
- **个人档**：家乡 / 现居地 / 职业 / 学校 / 感情状态。

## 留言板（KZoneMessageBoardCfg）

- 只列出 `roles[1] == 当前空间主人` 的留言。
- 每条：留言人（点击更换，写 `roles[0]`）、内容 `content`、公开/私密 `isPrivate`、
  普通/回复 `reply`、删除。
- 「＋ 添加留言」：选留言人后新建行，`id` 取全表最大值 +1，`roles = [留言人, 主人]`。

## 头像选择

- 读 `KZoneAvatarCfg`（`id → icon`），网格列出可复用头像；「使用大头照」= `icon = 0`
  （回退到人物立绘首字/头像）。
- `KZoneAvatarCfg` 只读（不在本界面编辑头像资源；资源管理见「素材库」）。

## 数据与保存

- **同时编辑两张表**，各自整表读写：
  - `KZoneProfileCfg`（空间资料，主键 = 人物 id）；
  - `KZoneMessageBoardCfg`（留言板）。
- 只读引用：`KZoneAvatarCfg`（头像）、`KZoneColorCfg`（主题）、`KZoneFontCfg`（字体）。
- 读取 `GET /api/cfg/<name>`（`data` + `mtime_ns`）；写回 `PUT` 带 `expect_mtime_ns`，
  409 逐表弹「重新加载 / 强制覆盖」。保存按 `KZoneProfileCfg → KZoneMessageBoardCfg` 顺序执行。
- 「保存修改」只写脏表；「放弃修改」回滚到本次加载快照。

## 当前版本的边界

- **不做签名图集实时渲染**：对标用游戏自带字体图集（`space-style.js` + 签名布局）
  把个性签名画成手写签名，这里用文本 `desc` 代替。
- **不做空间 BGM 播放**：只保存 `bgm` 编号；不内置本地 MP3 播放器（与整体决策一致）。
- **不做头像导入 / 裁剪**：只从既有 `KZoneAvatarCfg` 选择，不新建头像资源。
- **说说（KZoneContentCfg）与评论不在本界面**：由「社交动态」工作台负责，空间只做引用提示。
- **留言板嵌套回复**（`comments` / `round`）未展开编辑，仅顶层留言。
- **主题/字体的黄钻门控仅为提示**：为便于预览，未真正禁用未开通时的选择。
