# 社交动态工作台（导演布局的专属功能界面）

「每个功能都有专属界面」重建的第 1 批第二个功能。落在
`frontend/lib/features/social/social_workbench.dart`，由导演工作台的「社交动态」
功能（`_DirectorFeature.social`）承载；主页「社交」卡片直接进入本工作台，
不再走通用配置表视图。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（188–224） | 搜索框 / ＋发布动态 / 删除这条动态 / 动态列表（发布人、标题或正文摘要、评论数） |
| 中（自适应） | 动态卡片（发布人、标题、正文、配图）+ 评论树 + 底部保存条 |
| 右（≥1000 显示，288–330） | 动态设置或评论设置 |

窄窗（<1000）自动隐藏右栏；<1250 收窄左右栏。

## 动态卡片

- 发布人：点击弹出人物选择器更换。
- 标题 / 正文：直接编辑。
- 配图：网格缩略图，悬停删除；「＋ 添加配图」走资源图片选择器（多选）。

## 评论树

- 评论 id 约定 `floor(commentId / 100) == postId`（与游戏一致）。
- 根评论 → 回复（parent 指向所属根评论）逐层缩进渲染。
- 「白雨可选评论 / 回复」以独立分组呈现（发言者为白雨）。
- 每条评论可：设置 / 回复 / 白雨可选 / 删除（删除会连同其触发的回复与选项一起删除）。
- 评论出现条件与评论效果的**条数**以标签提示。

## 右栏设置

- **动态设置**：点赞人物（多选 + 每个延迟秒数）、白雨可选评论（chip，可跳转）、
  发布条件条数概览。
- **评论设置**：发言者（可更换）、白雨可回复（chip + 添加）、出现条件 / 评论效果
  条数概览、删除评论。

## 数据与保存

- 两张表整表读写：`KZoneContentCfg`（动态）/ `KZoneCommentCfg`（评论与回复）。
- 读取 `GET /api/cfg/<name>`（`data` + `mtime_ns`）。
- 写回 `PUT /api/cfg/<name>`，带 `expect_mtime_ns`；409 弹「重新加载 / 强制覆盖」。
- 「保存修改」一次写回两张表的脏数据；「放弃修改」回滚到本次加载快照。

## 当前版本的边界

- **发布条件 / 评论条件 / 评论效果**（金钱、好感、状态变化等命令）未内嵌条件与效果
  编辑器，右栏只显示条数概览；这些复杂命令在通用配置表里维护。
- **游戏内版式预览与时间线模拟**（点赞/评论按时序出现）未接入。
- 头像用「人物首字 + 配色」的占位方块，未加载企鹅空间头像贴图。
- 表情（企鹅表情图集）与配图导入未接入。
