# 物品仓库工作台（导演布局的专属功能界面）

「每个功能都有专属界面」重建的第 2 批第五个（也是第 2 批最后一个）功能。落在
`frontend/lib/features/warehouse/warehouse_workbench.dart`，由导演工作台的
「物品仓库」功能（`_DirectorFeature.warehouse`）承载；主页「物品仓库」卡片直接进入。

把对标的「物品仓库」与「商店仓库」两个 kind 合并为同一工作台的两种模式：
**物品**（`ItemCfg` + `BookCfg` 书籍）与**商店**（`ShopCfg`）。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（260–300） | 物品 / 商店模式切换、搜索、类型筛选、＋新建 / ＋上架、删除、改编号、条目列表（图片、名称、类型或价格、编号） |
| 中（自适应） | 条目详情：基本信息 / 效果指令 / 标签（页内分段），底部保存条 |
| 右（≥1080 显示，280–320） | 游戏内预览卡片 + 统计与引用 |

窄窗（<1080）自动隐藏右栏；<1340 收窄左右栏。

## 物品模式（ItemCfg + BookCfg）

- 列表同时汇总 `ItemCfg` 与 `BookCfg`，按编号排序；类型筛选把书籍归到「书籍」。
- **普通物品基本信息**：名称 `name`、类型 `type`、赠送价值 `value`、出售价格 `sell`、
  数量上限 `maxcount`、使用后对话 `talkId`、物品说明 `desc`。
- **书籍基本信息**：名称 `name`、书籍类别 `type`（3001 故事 / 3002 知识）、总页数
  `capacity`、赠送价值 / 出售价格、阅读提示文字 `talk`、物品说明 `desc`。
- **高级扩展选项**（折叠）：
  - 物品：稀有度 `rarity`、适用性别 `sex`、细分类别 `subType`、服装类别 `clothType`、
    所需扩展内容编号 `needDLC`、使用按钮文字 `btn`；
  - 书籍：阅读要求参数 `need`（逗号分隔）、书籍主题 `themes`（`BookThemeCfg` 多选）。
- **效果指令**：获得/阅读效果 `effect`、使用效果 `usingEffect`、使用条件 `precondition`，
  点击「打开积木库」可视化编辑（效果 / 效果 / 条件模式）。
- **标签**：`itemTag` 多选（只列出 `ItemTagCfg` 中 id < 100 的物品标签），支持手工输入编号。

## 商店模式（ShopCfg）

- ＋上架商品：从尚未上架的物品/书籍中选择，自动带出 `type` 与 `price`（物品取 `sell`）。
- 编辑：购买价格 `price`、数量上限 `maxcount`、上架概率 `probability`、开始出售年份 `time`、
  打折回合 `discountRound`、停止出售时间 `disappearTime`、购买数量限制 `limcount`、
  互斥商品组 `group`、售完替换商品 `next`、店员台词 `buyTalk`。
- **条件**：上架条件 `precondition` 复用积木库（条件模式）。

## 数据与保存

- **同时编辑三张表**，各自整表读写：
  - `ItemCfg`（物品）；
  - `BookCfg`（书籍）；
  - `ShopCfg`（商店）。
- 只读字典：`ItemTypeCfg`（类型名）、`ItemTagCfg`（标签名）、`BookThemeCfg`（书籍主题名）。
- 读取 `GET /api/cfg/<name>`（`data` + `mtime_ns`）；写回 `PUT` 带 `expect_mtime_ns`，
  409 逐表弹「重新加载 / 强制覆盖」。保存按 `ItemCfg → BookCfg → ShopCfg` 顺序只写脏表。
- 「保存修改」写回脏表；「放弃修改」回滚到本次加载快照。

## 当前版本的边界

- **不做「原版参考」来源浏览**：对标可切换当前模组 / 原版参考并复制到模组；
  这里只编辑当前模组的表（与其它工作台一致）。
- **不做跨表编号迁移**：改编号只重命名同表主键，不会同步商店 / 事件等对本编号的引用；
  对话框内已提示需自行核对。
- **不做物品副本 / 右键菜单**：对标支持“创建副本”与右键菜单，这里未接入。
- **不做图片导入 / 裁剪**：图片只从既有素材库选择，不新建资源。
- **改编号后 ShopCfg 的商品映射**：商店以 `id` 关联商品，若物品改了编号，商店条目会失去
  商品名（显示为原行数据），需手动重建。
- **效果 / 条件不内嵌零代码行列表**：统一经「打开积木库」编辑，保持与积木库一致的结果。
- **商店类型只读**：商品类型由所关联物品决定，不在商店侧单独编辑。
