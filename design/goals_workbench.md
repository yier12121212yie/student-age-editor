# 目标工作台（导演布局的专属功能界面）

「每个功能都有专属界面」重建的第 1 批第四个功能（本批收官）。落在
`frontend/lib/features/goals/goals_workbench.dart`，由导演工作台的
「目标工作台」功能（`_DirectorFeature.goals`）承载；主页「目标工作台」卡片直接进入，
不再走通用配置表视图。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（196–236） | 搜索框 / ＋添加目标 / 创建副本 / 删除目标 / 目标列表（图像、标题、描述摘要） |
| 中（自适应） | 游戏内目标预览（状态切换 + NGA 风格卡片）+ 保存条 |
| 右（≥1000 显示，292–340） | 目标设置（基本设置 / 完成要求 / 奖励与失败 / 扩展设置 标签） |

窄窗（<1000）自动隐藏右栏；<1250 收窄左右栏。

## 目标预览

用一张目标卡片模拟游戏内呈现：目标图像（人物首字占位）、标题、描述、
「完成要求 N 条 / 完成奖励 N 条 / 失败效果 N 条」标签、持续回合 / 截止回合，
以及移除规则、前置目标、后续目标组摘要。顶部可切换
**进行中 / 已完成 / 已失败** 预览状态（边框随之变色）。

## 设置标签

- **基本设置**：目标标题、目标图像（人物选择器）、移除规则（领取奖励后移除 /
  完成时自动移除 / 仅通过效果移除）、持续回合、目标描述。
- **完成要求**：`demand` 条数概览（达成条件在通用配置表维护）。
- **奖励与失败**：`reward` / `fail` 条数概览 + 完成后对话 / 失败后对话
  （TalkCfg 选择器，可增删多个）。
- **扩展设置**：出现条件条数概览、前置目标（IntentCfg 下拉）、后续目标组、
  目标组、截止回合、随机权重、目标分类（支线 / 主线 / 计划）、优先匹配的人生观
  （RenshengguanTypeCfg 下拉）。

## 数据与保存

- 单表整表读写：`IntentCfg`。
- 读取 `GET /api/cfg/IntentCfg`（`data` + `mtime_ns`）；写回 `PUT`，带
  `expect_mtime_ns`；409 弹「重新加载 / 强制覆盖」。
- `TalkCfg` / `RenshengguanTypeCfg` 懒加载用于对话与人生观下拉。
- 「保存修改」写回脏数据；「放弃修改」回滚到本次加载快照。

## 当前版本的边界

- **完成要求 / 出现条件（demand / condition）与奖励 / 失败效果（reward / fail）**
  未内嵌条件与效果编辑器，只显示条数；这些命令在通用配置表里维护。
- **目标图像自定义图片上传**未接入：图像用人物（PersonCfg / 角色目录）首字占位。
- **游戏内目标界面贴图**（`/api/goal-ui` sprite）与放大预览未接入，
  用目标卡片替代。
