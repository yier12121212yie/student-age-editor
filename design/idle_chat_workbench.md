# 闲聊工作台（导演布局的专属功能界面）

「每个功能都有专属界面」重建的第 2 批第三个功能。落在
`frontend/lib/features/chats/idle_chat_workbench.dart`，由导演工作台的
「闲聊」功能（`_DirectorFeature.chats`）承载；主页「闲聊」卡片直接进入。

## 布局（三栏）

| 栏 | 内容 |
| --- | --- |
| 左（260–300） | 搜索框 / ＋添加闲聊 / 删除此闲聊 / 闲聊列表（进度文字、人物、句数） |
| 中（自适应） | 闲聊设置 + 对白链（线性编辑）+ 保存条 |
| 右（≥1040 显示，300–340） | 进度文字标题 / 概览 / 对话预览气泡 |

窄窗（<1040）自动隐藏右栏；<1320 收窄左右栏。

## 闲聊设置（InteractCfg）

- **进度文字** `text`：显示在右下角「正在和谁……」的进度条文字。
- **闲聊人物** `npc`：人物选择器（选择后同步 `name`）。
- **闲聊地点** `map`：从 `game_dicts.maps` 选一个地点（空 = 不限地点）。
- **触发条件** `cond` / **闲聊效果** `effect`：点击**直接打开积木库**可视化编辑
  （条件 `condition` 模式 / 效果 `effect` 模式），完成写回 2D 数组。

## 对白链（TalkCfg）

- 入口 `talkId` 起，沿 `nextTalk[0]` 串成**线性对白链**。
- 每句：说话人胶囊（点击更换，白雨 = 0）、对白内容（直接编辑）、删除（带确认，
  删除后自动把上一句 `nextTalk` 接到下一句）。
- 「＋ 白雨对白」/「＋ {人物}对白」在链尾追加新 `TalkCfg` 行（id 取全表最大值 +1）。
- 右侧「对话预览」按聊天样式渲染气泡：白雨靠右、人物靠左，点击气泡跳到该句。

## 数据与保存

- **同时编辑两张表**，各自整表读写：
  - `InteractCfg`（闲聊定义）；
  - `TalkCfg`（对白内容）。
- 读取 `GET /api/cfg/<name>`（`data` + `mtime_ns`）；写回 `PUT` 带 `expect_mtime_ns`，
  409 逐表弹「重新加载 / 强制覆盖」。保存按 `InteractCfg → TalkCfg` 顺序执行。
- 「保存修改」写回两表脏数据；「放弃修改」回滚到本次加载快照。

## 当前版本的边界

- **没有原生立绘舞台与实时渲染**：对标用游戏自带 `DialogueStage` 做 16:9 实时预览，
  这里用聊天气泡列表替代（未接 Live2D / 立绘）。
- **表情按钮**（`roles` 的 `[role, 3000, face]` 表情层）未接入。
- **气泡表情 / 场景背景选择**（对标按行设置 `bg` 与社交表情）未接入。
- **年级切换（小学 / 中学）预览**未接入。
- **游戏参考库来源**（对标可浏览原版 `InteractCfg` 并复制到模组）未接入。
- 对白链只处理 `nextTalk` 主线；分支 `nextTalk2` / 选项不在闲聊界面内编辑。
