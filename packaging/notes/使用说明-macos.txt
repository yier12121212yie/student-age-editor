学生时代模组编辑器（macOS）
==============================

安装方式（任选其一）

1) DMG 拖拽安装（全量）
    打开 学生时代模组编辑器-vX.Y.Z-macos.dmg，
    将 学生时代模组编辑器.app 拖入 Applications 文件夹。

2) PKG 组件安装（可勾选）
    双击 学生时代模组编辑器-vX.Y.Z-macos.pkg，按向导勾选：
        组件   Core（必选）、GUI / TUI / CLI（至少选一个）、
               官方资源扩展包（适用于未安装游戏的创作者）
        命令   editor-gui / editor-tui / editor-cli 是否加入 PATH
    安装到 /Applications/学生时代模组编辑器.app。
    首次打开若被 Gatekeeper 拦截，见下方「首次运行」。
    macOS 无桌面图标惯例，故无该选项。

3) 便携 zip
    解压得到 学生时代模组编辑器.app，直接使用。

首次运行
    本版本为 ad hoc 签名，未做 Apple 公证。从浏览器/网盘下载后文件带
    「隔离」标记，首次打开可能被 Gatekeeper 拦截，按提示文案区分处理：

    - 提示「无法验证开发者」：
          右键点击 app -> 打开 -> 在弹窗中再点「打开」。
          若系统未提供该入口，用下面的 xattr 命令。

    - 提示「已损坏，无法打开。你应该将它移到废纸篓」：
          这是隔离标记叠加未公证导致的提示，并非文件真的损坏，
          不要点「移到废纸篓」。执行下面一行去除隔离标记后即可打开：

        xattr -dr com.apple.quarantine "/Applications/学生时代模组编辑器.app"

      （便携 zip 请改成解压后 .app 的实际路径；也可直接把 .app
        从终端窗口拖进来自动补全路径。）
      注：macOS 15 (Sequoia) 起，右键 -> 打开 的旧绕过方式对
          未公证应用已不再生效，须用上面的 xattr 命令。

    去除隔离后无需安装 Python 或 Flutter，双击即可运行。

命令行
    PKG 安装时按勾选创建于 /usr/local/bin：
        editor-gui    启动图形界面
        editor-tui    终端字符界面
        editor-cli    命令行接口
    便携模式可直接运行 app 内后端：
        学生时代模组编辑器.app/Contents/MacOS/backend_tui
        学生时代模组编辑器.app/Contents/MacOS/backend_cli

数据与日志位置
    安装到 /Applications（root 所有）时自动使用
    ~/Library/Application Support/StudentAgeEditor/
    （logs/、_cache/、editor_env.json）；便携目录可写时与 app 同级。

官方资源扩展包
    PKG 勾选该组件后开箱可用（随包内嵌，只读）；便携 zip / DMG 内
    app 自带 official_pack/ 目录时同样生效。

模组位置
    游戏无原生 macOS 版；CrossOver/Wine 用户请在首次启动向导（OOBE）
    中手动指向 bottle 内的 Mods 目录
    （默认给出 ~/Library/Application Support/ 下的等价路径）。

签名说明
    本版本为 ad hoc 签名，未做 Apple 公证（因此没有 Apple 开发者证书
    带来的「已验证开发者」标识）。首次打开按上面「首次运行」处理即可。
    打包已在注入内置后端后统一重签，app 签名封印完整；「已损坏」提示
    仅由下载隔离标记引起，xattr 去除后即消失。
    若需正式分发，请在 CI 中配置 Developer ID 签名与公证后再发布。

疑难排查
    - 提示「无法验证开发者」：右键 -> 打开，或用 xattr 命令去隔离。
    - 提示「已损坏，无法打开」：不要移到废纸篓，执行
          xattr -dr com.apple.quarantine "/Applications/学生时代模组编辑器.app"
    - 提示「Apple 无法验证……是否打开」且无「打开」按钮：同上用 xattr。
    - 后端无法启动：查看日志 backend.log 并反馈。
