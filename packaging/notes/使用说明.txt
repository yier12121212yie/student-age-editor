学生时代模组编辑器 v1.3.0
==============================

【运行】
    双击「学生时代模组编辑器.exe」即可使用，无需安装 Python 或 Flutter。
    首次启动时本地服务解压需要数秒，请稍候。

【v1.3.0 更新内容】
    - 首个多平台版本：同时提供 Windows / Linux / macOS / Android 发行版
    - Linux/macOS：后端以同名 backend 可执行文件随包分发，自动拉起
    - Android：后端以 Chaquopy 内嵌 CPython 方式运行，无需后台进程

【目录结构】
    学生时代模组编辑器.exe   主程序（双击运行）
    backend.exe   本地服务（主程序自动启动，请勿手动运行）
    data/、*.dll   程序运行所需文件，请勿删除
    logs/   运行日志（后端启动异常时可查看 backend.log）

【模组位置】
    默认工作区：%%USERPROFILE%%\AppData\LocalLow\PakyiGame\StudentAge\Mods

【常见问题】
    - 杀毒软件可能误报 backend.exe，请添加信任后重试。
    - 若程序无法启动，请将 logs\backend.log 内容反馈给开发者。
