HOW IT WORKS

一句话改模，每一步都可控

AI 不是黑箱：所有写入先给你看字段级 diff，批准才落盘，随时可撤销、可回滚。

  1. 1

    描述需求

    自然语言即可：「把开局事件的标题改成新的开始，并给第一句对白配音」。信息不足时 AI 会先向你提问。

  2. 2

    定位与生成

    15 个内置领域工具跨全部配置表查字典、查记录、生成改动；复杂调研最多派 4 个只读子代理并行处理。

  3. 3

    diff 审批

    字段级新旧对照：GUI 弹窗确认，CLI / TUI 以 y / N 应答；没有你批准的改动不会落盘。

  4. 4

    安全落盘

    原子替换写入，上一代自动留 .bak；写错可撤销 / 重做，跨表引用一键校验。

FEATURES

为改 Mod 而生的完整工作台

从查找、编辑到备份、发布——GUI、CLI、TUI 共享同一套工作区与配置，一个入口做完所有事。

同步语义与安全

  • 三种方向：upload（本地 → 远端）、download（远端 → 本地）、sync（双向，以新者为准）
  • 支持 --dry-run 试运行预览、--delete-extra 清理远端多余文件

命令作用操作
python run_cli.py mods list列出全部 Mod（含创意工坊，workshop 只读不可删）
python run_cli.py cfg get EvtCfg --mod test --id 320101查看单条记录（大表默认前 30 行）
python run_cli.py cfg set EvtCfg --mod test --id 320101 --key title --value "新的开始"修改单个字段（写盘前自动保留 .bak）
python run_cli.py cfg add TalkCfg --mod test新建记录，schema 自动填默认值，ID 取 max+1
python run_cli.py cfg validate --mod test校验 schema 与跨表引用（error 阻止 / warn 放行；v0.3 支持悬挂引用一键修复）
python run_cli.py agent chat -m test 把开局事件的标题改成「新的开始」AI 单次任务：工具调用 → 字段级 diff → 你确认 y/N
python run_cli.py cloud sync 备份 --mod test云同步上传（upload 由本地 → 远端）
python run_cli.py update检查新版本（比对 GitHub Release）

FAQ

常见问题

免费吗？需要买什么？

目前所有平台发行版均可免费下载使用。AI 助手与 TTS 需要你自己准备对应服务商（OpenAI 兼容 / Anthropic / 阿里云百炼 / MiniMax 等）的 API Key，按服务商计费；未配置时编辑器给出引导而不是报错。

安全吗？我的 Mod 数据会去哪？

数据默认只在本机处理：后端是本地 127.0.0.1 服务，CLI / TUI 甚至可以不启动 HTTP 服务完全离线运行。写盘采用原子替换并自动保留上一代 .bak，误写可回滚；v0.3 起还有乐观锁冲突检测与撤销 / 重做兜底。AI 密钥、网盘令牌等敏感配置不随 Mod 分发。个别杀毒软件可能对 backend.exe 误报，添加信任即可。

我的 Mod 文件放在哪里？

默认工作区是 %USERPROFILE%\AppData\LocalLow\PakyiGame\StudentAge\Mods（与图形版一致）。Linux 会自动探测 Steam 库与 compatdata/1991040/pfx 内的 Mods 目录；也可以用 workspace set <路径> 或 editor_env.json 自定义。

支持哪些平台？

Windows / macOS / Linux / Android 四平台均有发行版。注意：游戏本体只有 Windows 版，Mac / Linux / Android 上适合直接编辑 Mod 的 JSON 与资源文件；Android 版暂不支持部分压缩纹理（ASTC / ETC / BC）与 FSB 音频的解码导出，不影响 JSON 编辑等核心功能。

和 Steam 创意工坊是什么关系？

编辑器会列出「我的 Mod + 已订阅的创意工坊 Mod」，方便一起查看与编辑。但 workshop 目录在编辑器里是只读的——不能删除，需在 Steam 客户端取消订阅。创建的 Mod 是否发布到创意工坊、以何种形式发布，请以游戏与平台的最新规则为准。

AI 助手要用我自己的 Key 吗？

是的，需自备。支持 openai_compatible / openai_responses / anthropic 三种协议与任意 baseUrl；配置存在 .editor_ai.json，GUI / CLI / TUI 三端共享、实时生效，也能在 TUI AI 面板里直接改。
